คู่มือการใช้งาน StructLab

โปรแกรมวิเคราะห์และออกแบบโครงสร้างคอนกรีตเสริมเหล็กบนเว็บ ใช้ได้ทั้งโครงข้อแข็ง 2 มิติและอาคาร 3 มิติ ตั้งแต่สร้างโมเดล วิเคราะห์ ออกแบบคาน เสา พื้น ฐานราก บันได จนถึงรายการคำนวณ ปริมาณวัสดุ และแบบ AutoCAD

ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องติดตั้ง และข้อมูลไม่ถูกส่งออกไปที่ใด · แนะนำ Chrome, Edge หรือ Safari รุ่นใหม่บนคอมพิวเตอร์ (จอ 1280 px ขึ้นไป)

ความรับผิดชอบ: StructLab เป็นเครื่องมือช่วยคำนวณ ผลทุกอย่างต้องได้รับการตรวจสอบโดยวิศวกรผู้มีใบอนุญาต ค่าตั้งต้นของมาตรฐาน (เช่น Ss, S1, Fa, Fv, R, V₅₀, ตารางสัมประสิทธิ์พื้น) ต้องตรวจกับมาตรฐานฉบับจริงก่อนใช้งาน

เริ่มต้นใช้งาน

โหมด 2D และ 3D

โหมด 3D (3d.html)โหมด 2D (index.html)
เหมาะกับอาคารทั้งหลังจากกริด เสา คาน พื้น ฐานรากโครงข้อแข็งระนาบ เช่น โครงหลังคา โครงอาคารหนึ่งแนว หรือแก้ไขโครงที่ตัดมาจาก 3D
สร้างโมเดลกรอกช่วงกริด ความสูงชั้น หน้าตัด แล้วโปรแกรมสร้างให้ตารางจุดต่อ/ชิ้นส่วน หรือวาดด้วยเมาส์
แรงพื้น (kg/m²), น้ำหนักบนคาน, ลม, แผ่นดินไหวแรงจุด แรงแผ่ แรงลมรายชั้น
ออกแบบคาน เสา (สองแกน) ฐานราก พื้น บันได + BOQ + DXFคาน เสา ฐานราก

สลับโหมดได้จากปุ่ม ← โหมด 2D / โหมด 3D → ที่มุมซ้ายบน ทั้งสองโหมดใช้ค่าตั้งค่าร่วมกัน (วัสดุ มาตรฐาน หน่วย ข้อมูลโครงการ) และหน้า 2D แสดงโครงของอาคาร 3D ได้ — ดู การเชื่อม 2D ↔ 3D

ขั้นตอนสั้น 10 ขั้น (โหมด 3D)

  1. เปิดหน้า โหมด 3D หรือเลือกอาคารจากเมนู ตัวอย่าง… เพื่อดูตัวอย่างที่ตั้งค่าไว้แล้ว
  2. ในการ์ด สร้างอาคารจากกริด กรอกช่วงกริดแกน X, Y และความสูงชั้น เช่น 3@5, 2@4.5, 4,3@3.5
  3. กรอกขนาดเสา คาน และกำลังวัสดุ fc', fy, fyt
  4. ติ๊ก คิดน้ำหนักจากพื้น แล้วใส่ความหนาพื้น SDL และ LL เป็น kg/m² (หรือใส่น้ำหนักบนคานเป็น kN/m)
  5. เลือกพื้นที่ลม และเปิดแรงแผ่นดินไหวถ้าต้องการ
  6. โปรแกรมวิเคราะห์และออกแบบให้อัตโนมัติทุกครั้งที่แก้ค่า (ดูแถบความคืบหน้ากลางจอ)
  7. ดูการ์ด สรุปการออกแบบ และ ฐานราก ทางขวา — ถ้ามีชิ้นไม่ผ่าน กด ⚙ ปรับขนาดอัตโนมัติ
  8. คลิกชิ้นส่วนในภาพเพื่อดูแรงและผลออกแบบ แก้ขนาดเฉพาะชิ้นได้
  9. กด รายการคำนวณ เพื่อดูและพิมพ์เป็น PDF, ดู BOQ และกด DXF เพื่อส่งแบบไป AutoCAD
  10. กด บันทึก เก็บไฟล์โปรเจกต์ .3d.json ไว้เปิดภายหลัง

บันทึก เปิดไฟล์ และหน่วย

  • บันทึกอัตโนมัติ: ทุกการแก้ไขถูกจำไว้ในเบราว์เซอร์เครื่องนั้น เปิดหน้าใหม่ก็ยังอยู่ (ถ้าล้างข้อมูลเบราว์เซอร์ หรือเปิดโหมดไม่ระบุตัวตน ข้อมูลจะหาย)
  • บันทึกเป็นไฟล์: ปุ่ม บันทึก ดาวน์โหลดไฟล์ .3d.json (3D) หรือ .json (2D) — ใช้ส่งต่อหรือเก็บสำรอง
  • เปิดไฟล์: ปุ่ม เปิด รับไฟล์โปรเจกต์ของ StructLab และในโหมด 3D รับไฟล์ .dxf จาก AutoCAD เพื่อนำเข้าเส้นกริด — ดู นำเข้า DXF
  • หน่วย: ปุ่ม kN–m / ตัน–m มุมขวาบนเปลี่ยนหน่วยที่แสดงผล การคำนวณภายในเป็น kN เสมอ ช่องกรอกข้อมูลส่วนใหญ่เป็น kN, m (น้ำหนักพื้นเป็น kg/m², กำลังวัสดุเป็น ksc)
เคล็ดลับ: ก่อนลองแก้อะไรมาก ๆ ให้บันทึกไฟล์ไว้ก่อน — กลับมาสถานะเดิมได้ด้วยปุ่มเปิดไฟล์

สร้างอาคารจากกริด

อาคารสร้างจากเส้นกริดแกน X (แนว 1, 2, 3 …) แกน Y (แถว A, B, C …) และความสูงชั้นจากล่างขึ้นบน ทุกจุดตัดกริดมีเสา และมีคานเชื่อมทุกแนวในทุกชั้น (แก้ให้ไม่เต็มกริดได้ — ดู รูปทรงอาคาร)

ช่องอื่น

  • เสา b × h: h วางตามแกน X, b ตามแกน Y (m)
  • คาน b × h: ความกว้าง × ความลึก (m)
  • fc', fy, fyt: กำลังคอนกรีต เหล็กยืน และเหล็กปลอก (ksc)
  • พื้นแข็ง: สมมติพื้นแข็งในระนาบ (rigid diaphragm) — แรงลม/แผ่นดินไหวกระทำที่จุดอ้างอิงพื้น ควรเปิดไว้
  • P-Δ / หน้าตัดแตกร้าว: ดู สมมติฐานการวิเคราะห์
วิเคราะห์อัตโนมัติ: แก้ช่องใดก็ตาม โปรแกรมรอครู่หนึ่งแล้ววิเคราะห์และออกแบบใหม่ให้เอง ไม่ต้องกดปุ่ม (ปุ่ม “วิเคราะห์ใหม่” ใช้บังคับคำนวณทันที) การคำนวณทำเบื้องหลัง หน้าจอจึงไม่ค้าง

น้ำหนักบรรทุกและแรง

พื้นสองทาง (น้ำหนักต่อพื้นที่ kg/m²)

ติ๊ก คิดน้ำหนักจากพื้น แล้วกรอก

  • t — ความหนาพื้น (m) น้ำหนักตัวเองคิดจาก 2,400 kg/m³ ให้อัตโนมัติ
  • SDL — วัสดุปู ฝ้า งานระบบ (kg/m²)
  • LL — น้ำหนักจรตามประเภทการใช้งาน (kg/m²)
  • ค่าหลังคาแยกต่างหาก

โปรแกรมกระจายน้ำหนักแผ่นพื้นลงคานรอบแผ่นด้วยเส้น 45° แล้วแปลงเป็นน้ำหนักแผ่สม่ำเสมอเทียบเท่า:

  • คานด้านสั้น (สามเหลี่ยม): w·S/3
  • คานด้านยาว (คางหมู): w·S/3·(3 − m²)/2, m = S/L
ระวังนับซ้ำ: เมื่อเปิดใช้พื้น ช่อง “น้ำหนักบนคาน” จะกลายเป็น “น้ำหนักเพิ่มเติม เช่น ผนัง” — ถ้ายังเป็นค่าตั้งต้น โปรแกรมจะล้างเป็น 0 ให้ กรอกเฉพาะน้ำหนักผนังที่วางบนคาน

น้ำหนักบนคาน (kN/m)

ช่อง SDL/LL ใต้หัวข้อ “น้ำหนักบนคาน” เป็นน้ำหนักแผ่สม่ำเสมอบนคานทุกตัว (แยกพื้นกับหลังคา) ใช้เมื่อไม่ได้เปิดพื้น หรือใช้เป็นน้ำหนักผนัง · ปรับเฉพาะคานบางตัวได้ในการ์ด แก้ไขชิ้นส่วน

ดูน้ำหนักที่กระทำจริงได้ด้วยปุ่ม น้ำหนัก — ลูกศรสีส้มคือแรงแผ่บนคาน สีฟ้าคือแรงที่จุด (เช่น ลม แผ่นดินไหว) ตาม load case หรือชุดผสมที่เลือก

แรงลม (มยผ. 1311-50 วิธีอย่างง่าย)

เลือก พื้นที่ (กลุ่มความเร็วลม), ภูมิประเทศ (A โล่ง / B เมือง), ความสำคัญ และ Cg โปรแกรมคำนวณแรงลมรายชั้นทั้งสองทิศ (WX, WY) กระทำที่จุดอ้างอิงพื้นแข็ง การ์ด “แรงลมรายชั้น” แสดงแรงแต่ละชั้นและแรงเฉือนฐาน

แรงแผ่นดินไหว (มยผ. 1301/1302-61 สถิตเทียบเท่า)

ช่องความหมาย
Ss, S1ความเร่งตอบสนองเชิงสเปกตรัมที่คาบ 0.2 และ 1.0 วินาที จากแผนที่ในมาตรฐาน (หน่วย g)
ชั้นดินA–E → ค่า Fa, Fv
Ie, R, Cdตัวประกอบความสำคัญ · ตัวประกอบปรับผลตอบสนอง (โครงต้านแรงดัดธรรมดา ค.ส.ล. = 3) · ตัวประกอบขยายการเคลื่อนตัว (2.5)
T (s)คาบ 0 = ใช้สูตร 0.02H · หรือใส่ค่าจากการวิเคราะห์การสั่น (ดู Modal)
%LLสัดส่วนน้ำหนักจรที่รวมในน้ำหนักอาคาร

โปรแกรมคำนวณ SDS, SD1, Cs = Sa·Ie/R, V = Cs·W แล้วกระจายแรงตามความสูง Fx = Cvx·V สร้าง load case EX, EY พร้อมแรงบิดจากการเยื้องศูนย์โดยบังเอิญ 5% และเพิ่มชุดผสมของ วสท. ให้

สำคัญ: ค่า Ss, S1, Fa, Fv, R เป็นค่าตั้งต้นที่แก้ได้ ต้องตรวจกับแผนที่และตารางในมาตรฐานฉบับจริง · กรุงเทพฯ และปริมณฑลใช้สเปกตรัมเฉพาะ ซึ่งยังไม่รองรับ

*:B2ช่อง B2 ทุกชั้น

ช่องเปิดไม่มีแผ่นพื้น คานรอบช่องจึงรับน้ำหนักพื้นจากด้านเดียว และแผ่นข้างเคียงจะคิดขอบนั้นเป็นขอบไม่ต่อเนื่อง

คานยื่น

กรอกความยาวยื่นแต่ละด้าน (−X ซ้าย, +X ขวา, −Y หน้า, +Y หลัง) และชั้นเริ่ม — โปรแกรมสร้างคานยื่นทุกแนวกริดของด้านนั้น ถ้าเปิดพื้น คานยื่นรับน้ำหนักพื้นยื่นตามความกว้างรับน้ำหนัก (ครึ่งช่วงสองข้าง) · คานยื่นชื่อ KX-… / KY-…

ลบเสา/คาน

คลิกชิ้นส่วน → การ์ด “แก้ไข” → เลือกขอบเขต (ชิ้นนี้ / ทั้งชั้น / ทั้งแนว) → 🗑 ลบ… ใช้กับเสาที่ไม่ต่อลงล่าง ชั้นบนที่ถอยร่น หรือช่วงที่ไม่มีคาน · คืนชิ้นที่ลบทั้งหมดได้ด้วยปุ่ม คืนทั้งหมด ในหัวข้อรูปทรงอาคาร

แผ่นพื้นอัตโนมัติ: ช่องที่คานขอบไม่ครบ 4 ด้านจะไม่มีแผ่นพื้นให้เอง

คานคอดิน

ติ๊ก มีคานคอดิน แล้วกำหนด b, h และน้ำหนักผนังชั้นล่าง (kN/m) — โปรแกรมสร้างคานที่ระดับฐานเชื่อมโคนเสาทุกแนว และเปลี่ยนฐานเสาเป็นแบบหมุนได้ โมเมนต์ที่ฐานจึงถ่ายไปที่คานคอดิน (ออกแบบเป็นคาน ชื่อ BX-…-0) ฐานรากรับเฉพาะแรงตามแกนและแรงเฉือน

เมื่อไหร่ควรใช้: อาคารที่มีแรงด้านข้างมาก (แผ่นดินไหว) ฐานแผ่จะรับโมเมนต์ไม่ไหว คานคอดินช่วยลดขนาดฐานรากได้มาก

เลือก load case หรือชุดผสมจากช่องข้างปุ่ม — ผลที่แสดงเปลี่ยนตามทันที กล่องคำอธิบายมุมซ้ายบนของภาพบอกค่าสูงสุด/ต่ำสุดและตำแหน่ง

มุมมองและการแสดงผล

ใช้ช่อง “ชั้น” เพื่อดูเฉพาะชั้นเดียว เหมาะกับการตรวจแปลนพื้นและน้ำหนักทีละชั้น

ตรวจการเคลื่อนตัวรายชั้น

  • ลม: Δ/h ของ load case WX/WY ≤ 1/500 (แก้เกณฑ์ได้ในตั้งค่าการออกแบบ)
  • แผ่นดินไหว: Δ = Cd·δe/Ie ≤ 0.020h และเสถียรภาพ θ = Px·Δ·Ie/(Vx·h·Cd) ≤ 0.5/Cd ≤ 0.25
  • ค่าที่จุดอ้างอิงพื้น · ถ้าเปิดหน้าตัดแตกร้าวจะได้ค่าสูงกว่าใช้งานจริง (ปลอดภัย)

การสั่นอิสระ (Modal)

  1. กด 〰 วิเคราะห์การสั่น ในการ์ด “การสั่นอิสระ” (ต้องเปิดพื้นแข็ง)
  2. ตารางแสดงคาบ T, ทิศหลักของโหมด (X, Y หรือบิด), สัดส่วนมวลประสิทธิผล และผลสะสม — ควรได้สะสม ≥ 90% ในแต่ละทิศ
  3. กด ▶ หน้าโหมดเพื่อดูการสั่นในภาพ 3D · กด ■ หยุด
  4. ถ้าเปิดแผ่นดินไหว กด ใช้ T = … s กับแรงแผ่นดินไหว — โปรแกรมใช้ค่าน้อยของ Tx, Ty แต่ไม่เกิน Cu·Ta = 1.4 × 0.02H ตามมาตรฐาน

เลือกและแก้ไขชิ้นส่วน

ชื่อชิ้นส่วนบอกตำแหน่ง: C-B2-1 = เสาที่กริด B2 ชั้น 1 (จากระดับ 1 ขึ้นไป 2) · BX-A1-2 = คานแนวแกน X เริ่มที่ A1 ระดับ 2 · BY-… คานแนวแกน Y · …-0 คานคอดิน · KX/KY คานยื่น

แก้ไขรายชิ้น

  1. แก้ b, h (และ SDL, LL สำหรับคาน)
  2. เลือก ใช้กับ: ชิ้นนี้ · ทั้งชั้น · ทั้งแนวกริด (เสา: ต้นนี้ทุกชั้น) — ตัวเลขในวงเล็บคือจำนวนชิ้นที่จะเปลี่ยน
  3. กด ใช้ค่านี้ โปรแกรมวิเคราะห์ใหม่โดยคงชิ้นที่เลือกและมุมกล้อง · ป้าย “ปรับรายชิ้น” บอกว่าชิ้นนี้ต่างจากค่าทั้งอาคาร
  4. คืนค่าทั้งอาคาร ล้างค่าปรับของชิ้นในขอบเขต · ปุ่ม ล้าง ในการ์ดสร้างอาคารล้างทั้งหมด

ปุ่ม ✎ แก้ไขในโครง 2D … เปิดโครงตามแนวกริดของชิ้นนี้ในหน้า 2D (เสาเลือกได้ทั้งแนว X และ Y)

การออกแบบ

ตั้งค่าการออกแบบ

เลือกมาตรฐาน วสท. 1008-38 (วิธีกำลัง) หรือ ACI 318-19, ระยะหุ้ม, ขนาดและจำนวนขาเหล็กปลอก และเกณฑ์ drift ลม — ค่าเหล่านี้ใช้ร่วมกับหน้า 2D

คาน

  • ดัด: เหล็กล่างจากโมเมนต์บวก เหล็กบนจากโมเมนต์ลบ (ค่าสุดขีดทุกชุดผสม) ตรวจ ρmin, ρmax และการวางเหล็กชั้นเดียว
  • เฉือน: ระยะเหล็กปลอกจากแรงเฉือน ระยะสูงสุด และเหล็กปลอกขั้นต่ำ
  • บิด (ACI 22.7): ถ้า Tu เกิน Tth จะออกแบบเหล็กปลอกปิดรับแรงบิดร่วมกับแรงเฉือน เหล็กตามยาว Al และเหล็กข้าง · ถ้าหน้าตัดเล็กเกินจะแจ้งให้ขยาย
  • จุดตัดเหล็ก: เหล็กบนเสริมยื่น ≥ Ln/3 จากผิวเสา เหล็กล่างเสริมตัดไม่เกิน 0.15Ln — แสดงภาพด้านข้างคานในรายการคำนวณ

เสา

ออกแบบเสาสองแกน (P–M33–M22) ด้วยวิธีความเข้ากันได้ของความเครียดที่ทุกมุมแกนสะเทิน รวมผลความชะลูด เลือกจำนวนและขนาดเหล็กยืน เหล็กปลอก และแสดงชุดผสมวิกฤต

ฐานราก

  • ฐานแผ่: กำหนด qa (t/m²), Df, L/B — ตรวจแรงดันดินสองทิศ (คิดการสัมผัสดินบางส่วน) แรงเฉือนทะลุ แรงเฉือนทางเดียว และเหล็กตะแกรง
  • ฐานเข็ม: กำหนดน้ำหนักปลอดภัยต่อต้น ขนาดเข็ม ระยะห่าง — เลือกจำนวนเข็มและขนาดฐาน
  • ข้อความไม่ผ่านบอกสาเหตุ เช่น “แรงถอน (เสารับแรงดึง) ในชุด 0.9D + 1.43EY” → แก้ด้วยเสาเข็มรับแรงถอน น้ำหนักถ่วง หรือรวมฐาน · “แรงลัพธ์นอกฐาน” → เปิดคานคอดิน
  • คลิกแถวในตารางหรือคลิกกล่องฐานรากในภาพ 3D เพื่อดูแปลนและขั้นตอนคำนวณ

พื้นสองทาง

ออกแบบด้วยวิธีสัมประสิทธิ์โมเมนต์ “วิธีที่ 2” (ACI 318-63 ที่ วสท. ใช้) — กรณี 1–5 ตามจำนวนขอบที่ไม่ต่อเนื่อง (ดูจากแผ่นข้างเคียงในกริด), M = C·wu·S² ต่อเมตร, ตรวจความหนา ≥ เส้นรอบรูป/180 เหล็กขั้นต่ำ ระยะเหล็ก ≤ 2t และแรงเฉือน แผ่นที่ m = S/L < 0.5 ออกแบบเป็นพื้นทางเดียว · แผ่นที่ได้เหล็กเหมือนกันรวมเป็นแบบ S-1, S-2 …

ตรวจตาราง: รายการคำนวณพิมพ์ตารางสัมประสิทธิ์ทั้งหมดที่ใช้ ให้ตรวจกับมาตรฐานฉบับจริง

บันได

บันไดท้องเรียบช่วงเดียว กรอกช่วงราบ Ln ความสูงระหว่างชานพัก ลูกนอน ความหนาท้องบันได ความกว้าง ชนิดฐานรองรับ และน้ำหนัก — ได้จำนวนขั้น ลูกตั้ง เหล็กหลัก เหล็กกันร้าว และแรงที่ลงคานรองรับ (ใช้เป็นน้ำหนักบนคานที่รับบันได) · ติ๊ก “ออกแบบบันได” เพื่อพิมพ์ในรายการคำนวณ

ปรับขนาดอัตโนมัติ

กด ⚙ ปรับขนาดอัตโนมัติ โปรแกรมขยายเฉพาะชิ้นที่ไม่ผ่าน แล้ววิเคราะห์ซ้ำจนผ่าน (สูงสุด 8 รอบ ทีละ 5 cm ไม่เกิน 1.50 m):

  • คานที่เหล็กวางชั้นเดียวไม่พอหรือแรงบิดเกิน → เพิ่มความกว้าง
  • คานที่กำลังไม่พอหรือ ρ เกิน → เพิ่มความลึกประมาณ h·√(อัตราส่วน)
  • เสาไม่ผ่าน → เพิ่มทั้งสองด้าน · ชั้นที่ drift เกิน → ขยายเสาชั้นนั้นตาม (Δ/ยอมให้)^¼

ผลเป็น “ค่าปรับรายชิ้น” — ย้อนกลับได้ด้วยปุ่ม ล้าง ในการ์ดสร้างอาคาร · ฐานรากไม่ปรับอัตโนมัติ (ให้ดูสาเหตุในการ์ดฐานราก)

ปริมาณวัสดุ (BOQ)

  • คอนกรีต (m³), แบบหล่อ (m²), เหล็กเสริม (kg) แยกคาน คานคอดิน เสา ฐานราก พื้น — จากผลออกแบบจริง
  • เหล็กแยกขนาด และค่าเฉลี่ยเหล็กต่อคอนกรีต (kg/m³) ใช้ตรวจความสมเหตุสมผล (อาคาร ค.ส.ล. ทั่วไป ~80–150 kg/m³)
  • แก้ราคาต่อหน่วยได้ (ค่าตั้งต้นเป็นราคาประมาณ วัสดุ + ค่าแรง) — ค่าใช้จ่ายรวมคำนวณใหม่ทันที
  • ปุ่ม CSV ดาวน์โหลดตารางไปเปิดใน Excel
ไม่รวม: เหล็กทาบ ค่าเผื่อสูญเสีย และค่าเสาเข็ม (แสดงเป็นจำนวนต้น)

รายการคำนวณ

กดปุ่ม รายการคำนวณ บนแถบเครื่องมือ (หรือปุ่ม “รายการคำนวณคานนี้/เสานี้/ฐานรากนี้” ในแผงขวา) จะเปิดเอกสารขนาด A4 พร้อมเลขหน้าและสารบัญ

  • ปุ่ม รายละเอียดทุกชิ้น สลับระหว่างพิมพ์เฉพาะชิ้นวิกฤตของแต่ละกลุ่ม (ค่าตั้งต้น) กับพิมพ์ทุกชิ้น
  • พิมพ์ / บันทึก PDF → เลือกเครื่องพิมพ์ “Save as PDF” ขนาด A4 ไม่ต้องย่อขยาย
  • ข้อมูลหน้าปก (เจ้าของโครงการ สถานที่ วิศวกร เลขใบอนุญาต) กรอกในการ์ด “ข้อมูลโครงการ”
  • หน่วยในรายการคำนวณตามที่เลือก kN หรือ ตัน

  4. โปรแกรมแสดงจำนวนเส้นกริดและช่วงที่พบ เช่น “แกน X: 5 เส้น → 4@6 m” กด OK เพื่อใช้เป็นช่วงกริดของอาคาร (ความสูงชั้น หน้าตัด น้ำหนักคงเดิม)

ผลและการออกแบบ

การเชื่อม 2D ↔ 3D

สิ่งที่ใช้ร่วมกันเสมอ

ชื่อโปรเจกต์ ข้อมูลโครงการ วัสดุ (fc', fy, fyt) มาตรฐานและค่าการออกแบบพื้นฐาน ตั้งค่าฐานราก แรงลม และหน่วย — แก้หน้าหนึ่ง อีกหน้าเปลี่ยนตาม (แม้เปิดคนละแท็บ)

โครง 2D จากอาคาร 3D (เชื่อมสองทาง)

  • เปิด: คลิกชิ้นใน 3D แล้วกด “← 2D: …” · หรือกด “โหมด 2D” เฉย ๆ เพื่อเปิดโครงที่เชื่อมไว้/แนวกริดกลาง · หรือเลือกแนวจากช่อง 🔗 โครงจาก 3D ในหน้า 2D
  • แก้ใน 2D → 3D: ขนาดหน้าตัดของชิ้น และน้ำหนักแผ่บนคาน (DL/LL) ส่งกลับเป็นค่าปรับรายชิ้นของอาคาร 3D ทันที
  • แก้ใน 3D → 2D: โครงสร้างใหม่ให้อัตโนมัติเมื่อสลับกลับมา (ชั้น ช่วง หน้าตัด น้ำหนัก ฯลฯ)
  • ข้อจำกัด: การแก้รูปทรงใน 2D (ย้าย/เพิ่ม/ลบชิ้น) ส่งกลับไม่ได้ — เมื่อ 3D เปลี่ยน โปรแกรมจะถามก่อนทับ · กด เลิกเชื่อม เพื่อแก้โครง 2D อิสระ
  • กู้คืน: โมเดล 2D เดิมของคุณถูกสำรองไว้ก่อนเปิดโครงจาก 3D — กด กู้โมเดล 2D เดิม บนแถบแจ้ง

ข้อจำกัดที่ควรรู้

  • ไม่มีชิ้นส่วนเอียง ผนังรับแรงเฉือน หรือแผ่นพื้น shell ในโมเดล 3D — พื้นถ่ายน้ำหนักลงคานด้วยวิธีเส้น 45°
  • จุดตัดเหล็กคานยังไม่ตรวจระยะฝัง ld และระยะทาบเต็มรูปแบบ
  • เสาชะลูดใช้วิธีขยายโมเมนต์ · ผลจากความแข็งแตกร้าวเป็นระดับกำลัง
  • ผลตรวจความถูกต้องเทียบผลเฉลยปิด 16 กรณีอยู่ในไฟล์ VERIFICATION.md ของโปรเจกต์ (คลาดเคลื่อน 0–0.7%)

คำถามพบบ่อย / แก้ปัญหา

ข้อมูลหายเมื่อเปิดเครื่องใหม่/เบราว์เซอร์อื่น

ข้อมูลอัตโนมัติเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ให้กด “บันทึก” เป็นไฟล์ แล้ว “เปิด” ในเครื่องอื่น

หน้า 2D กับ 3D ไม่ตรงกัน

ดูช่อง “🔗 โครงจาก 3D” ในหน้า 2D — ถ้าขึ้น “(โมเดลนี้ไม่ได้เชื่อม)” ให้เลือกแนวกริดที่ต้องการ หรือกลับไปหน้า 3D แล้วกด “← โหมด 2D”

คาน/เสาไม่ผ่านจำนวนมาก

ดูอัตราส่วนและข้อความในการ์ดออกแบบของชิ้นนั้น แล้วกด “⚙ ปรับขนาดอัตโนมัติ” หรือเพิ่มขนาดทั้งอาคาร · ถ้าเปิดแผ่นดินไหว ตรวจค่า Ss/S1/R ให้ถูกต้องก่อน

ฐานรากไม่ผ่าน “แรงถอน” หรือ “แรงลัพธ์นอกฐาน”

เกิดกับเสามุมในชุด 0.9D ± E — เปิดคานคอดิน ใช้ฐานเข็มรับแรงถอน เพิ่มน้ำหนักถ่วง หรือรวมฐาน

“โครงสร้างไม่มีเสถียรภาพ”

มักเกิดจากลบเสาหรือคานจนบางส่วนลอย หรือจุดรองรับไม่พอ — กด “คืนทั้งหมด” ในหัวข้อรูปทรงอาคาร แล้วลบใหม่ทีละน้อย

วิเคราะห์ช้า

อาคารใหญ่มาก (หลายพันชิ้น) และเปิด P-Δ ใช้เวลามากขึ้น — ปิด P-Δ ระหว่างทดลองแบบ แล้วเปิดตอนตรวจขั้นสุดท้าย
