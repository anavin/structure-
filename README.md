# StructLab — วิเคราะห์และออกแบบโครงข้อแข็ง 2D (MVP)

โปรแกรมบนเบราว์เซอร์สำหรับวิเคราะห์โครงข้อแข็ง 2 มิติด้วยวิธีความแข็งโดยตรง และออกแบบคาน ค.ส.ล. ตาม วสท. 1008-38 (SDM) / ACI 318-19

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173 (2D) และ /3d.html (3D)
npm test         # ชุดทดสอบเทียบผลเฉลย (93 กรณี)
npm run build    # สร้างไฟล์ static ใน dist/
```

## ข้อจำกัดของรุ่นนี้
- ยังไม่มีจุดรองรับสปริง, การทรุดตัว, ปลดแรงเฉือน/แรงตามแกน
- P-Delta ใช้ชิ้นส่วนละ 1 element (คลาดเคลื่อน < 2% สำหรับ P ≤ 0.3Pcr) — แบ่งชิ้นส่วนย่อยเพื่อความแม่นยำมากขึ้น
- ชุดผสมแต่ละชุดวิเคราะห์แยกกัน (ถูกต้องสำหรับ P-Delta) ส่วนผลรายกรณีที่แสดงเป็นผลเดี่ยวไม่ใช่ผลรวม
- ออกแบบคานแบบเสริมเหล็กรับแรงดึงชั้นเดียว ใช้ Vu สูงสุด (ไม่ลดที่ระยะ d)
- เสา: ดัดแกนเดียว (ในระนาบ); การเซแยกชั้นตามระดับปลายเสา — โครงที่ชั้นไม่ตรงระดับกันยังไม่รองรับ
- โมเมนต์อันดับหนึ่งใช้ Ig เต็ม (Q ใช้ความแข็งแตกร้าวแล้ว)
- ฐานราก: โมเมนต์แกนเดียว, เข็มเรียงแบบตาราง (ไม่มีแบบ 3 ต้นสามเหลี่ยม), ไม่ตรวจระยะฝังยึดเหล็กและแรงแบกทานที่ผิวสัมผัสเสา
- แรงลม: วิธีอย่างง่ายเท่านั้น (H ≤ 80 m, H/D ≤ 3), ค่า V₅₀/TF/Iw/Cp ตั้งต้นต้องตรวจกับมาตรฐานฉบับจริง
- ยังไม่มีแรงแผ่นดินไหว

## โหมด 3D (`3d.html`)
ความเร็ว (Node, เครื่องพัฒนา) ไม่มี / มี rigid diaphragm: 10 ชั้น 960 ชิ้นส่วน 0.10 / 0.05 s · 20 ชั้น 4,500 ชิ้นส่วน 1.8 / 0.4 s · 30 ชั้น 10,230 ชิ้นส่วน 9.1 / 1.5 s
Rigid diaphragm: ใช้ `autoDiaphragms(model)` (หนึ่งชุดต่อระดับ z) หรือกำหนดเอง; แรงที่จุดอ้างอิงใส่ด้วย nodal load ที่ node = id ของ diaphragm · แรงตามแกนในคานที่อยู่ใน diaphragm ไม่มีความหมาย (เหมือน ETABS)
P-Δ + หน้าตัดแตกร้าวเปิดเป็นค่าตั้งต้น: เสาใช้โมเมนต์อันดับสองโดยตรง (ACI 6.7) รวมโมเมนต์สูงสุดกลางเสา · drift ที่แสดงจึงเป็นค่าที่ใช้ความแข็งแตกร้าว (ระดับกำลัง)
ฐานรากใน 3D: ตั้งค่าในแผงซ้าย, กล่องฐาน/เข็มใต้จุดรองรับ, คลิกกล่องหรือแถวในตารางเพื่อดูแปลนและขั้นตอนคำนวณ · ปุ่ม เปิด/บันทึก เก็บโปรเจกต์ 3D เป็นไฟล์ `.3d.json` · มุมมอง Perspective/Orthographic, ปุ่ม ขนาดจริง (วาดเสา/คานเป็นแท่งตามหน้าตัด), ปุ่มแสดง/ซ่อน แกน XYZ (แกนมุมจอแสดงตลอด) · ปุ่ม รายการคำนวณ: สรุป + ชิ้นวิกฤต หรือรายละเอียดทุกชิ้น, และปุ่มรายการคำนวณในการ์ดของแต่ละชิ้น/ฐาน
ยังไม่มี: ออกแบบเหล็กรับแรงบิด, แผ่นพื้น shell, การเยื้องศูนย์โดยบังเอิญของแรงลม

## ค่าร่วม 2D ↔ 3D และตัวอย่าง
- หน้า 2D และ 3D ใช้ค่าชุดเดียวกัน (`src/shared/shared.ts`, localStorage + แจ้งข้ามแท็บ): ชื่อ/ข้อมูลโครงการ, วัสดุ fc'/fy/fyt, ตั้งค่าออกแบบ (มาตรฐาน ระยะหุ้ม ปลอก), ตั้งค่าฐานราก, แรงลม และหน่วย kN/ตัน — เรขาคณิตและน้ำหนักบรรทุกยังแยกกัน
- ปริมาณวัสดุ BOQ (3D, `src/design/boq3d.ts`): คอนกรีต m³ · แบบหล่อ m² · เหล็กเสริม kg แยกขนาด จากผลออกแบบจริงของคาน เสา คานคอดิน ฐานราก และพื้น · ราคาต่อหน่วยแก้ได้ · ดาวน์โหลด CSV · หน้า BOQ ในรายการคำนวณ (ประมาณ: ไม่รวมเหล็กทาบ/เผื่อสูญเสีย/เหล็กพื้น/เสาเข็ม)
- ตรวจการเคลื่อนตัวรายชั้น (3D, `src/design/drift3d.ts`): ลม Δ/h ≤ 1/500 (แก้ได้ในตั้งค่าการออกแบบ) · แผ่นดินไหว Δ = Cd·δe/Ie ≤ 0.020h (Cd ตั้งต้น 2.5) และเสถียรภาพ θ = PΔIe/(VhCd) ≤ 0.5/Cd ≤ 0.25 · แสดงในแผงขวาและรายการคำนวณ · ปุ่มปรับขนาดอัตโนมัติขยายเสาของชั้นที่ drift เกินด้วย (ขนาด × (Δ/ยอมให้)^¼)
- ปรับขนาดอัตโนมัติ (3D): ปุ่ม ⚙ ในการ์ดสรุปการออกแบบ ขยายเฉพาะคาน/เสาที่ไม่ผ่านแล้ววิเคราะห์ซ้ำจนผ่าน (สูงสุด 8 รอบ) — คาน: เหล็กวางชั้นเดียวไม่พอ/แรงบิดเกิน → เพิ่ม b, กำลังไม่พอหรือ ρ เกิน → เพิ่ม h ≈ h·√ratio; เสา: เพิ่มสองด้าน ≈ ·√ratio; ทีละ 5 cm สูงสุด 1.50 m · ผลเป็นค่าปรับรายชิ้น ล้างได้ (`src/design/autosize3d.ts`)
- หน้าตัดแตกร้าว (3D) ลดความแข็งบิดของคานเป็น 0.10J (แรงบิดแบบสอดคล้อง ACI 22.7.3.2) — คานไม่ดึงแรงบิดเกินจริง
- พื้นสองทาง (3D): ป้อนความหนาพื้นและน้ำหนัก SDL/LL เป็น kg/m² (แยกหลังคา) → กระจายลงคานรอบแผ่นด้วยเส้น 45° เป็นน้ำหนักแผ่เทียบเท่า ด้านสั้น wS/3 ด้านยาว wS/3·(3 − m²)/2 · น้ำหนักบนคาน kN/m เดิมใช้เป็นน้ำหนักเพิ่มเติม (ผนัง) · น้ำหนักอาคารสำหรับแผ่นดินไหวใช้พื้นที่แผ่นจริง · ยังไม่ออกแบบเหล็กเสริมพื้น
- คานคอดิน (3D): เปิดในการ์ดสร้างอาคาร (b, h, น้ำหนักผนัง kN/m) → คานระดับ 0 เชื่อมโคนเสาทุกแนว ฐานเสาหมุนได้ โมเมนต์ที่ฐานไปที่คานคอดิน ซึ่งวิเคราะห์/ออกแบบเป็นคาน (ชื่อ BX-…-0 / BY-…-0) ปรับรายชิ้น ปรับขนาดอัตโนมัติ และเปิดในโครง 2D ได้ · ฐานรากรับแรงตามแกน + แรงเฉือน
- ฐานแผ่ 3D รายงานชุดแรงประลัยที่ทำให้แรงลัพธ์อยู่นอกฐานหรือเกิดแรงถอน (เสารับแรงดึง) แทนข้อความ "ความหนาไม่พอ"
- แก้ไขรายชิ้นในหน้า 3D: คลิกคาน/เสา → การ์ด "แก้ไข" ในแผงขวา ปรับ b × h และ SDL/LL ของคาน ใช้กับชิ้นนี้ / ทั้งชั้น / ทั้งแนวกริด (เสา: ต้นนี้ทุกชั้น) หรือคืนค่าทั้งอาคาร — วิเคราะห์ใหม่โดยคงชิ้นที่เลือกและมุมกล้อง
- หน้า 2D แสดงโครงของอาคาร 3D เสมอ: กด "โหมด 2D" โดยไม่เลือกชิ้น → เปิดโครงที่เชื่อมไว้ หรือแนวกริดกลางตามแกน X · เปิดหน้า 2D ครั้งแรกใช้โครงจากอาคาร 3D แทนตัวอย่าง · ช่อง "โครงจาก 3D" ในแถบบนสลับแนวกริดได้ (โมเดล 2D อิสระสำรองไว้ กู้คืนได้)
- โครง 2D ที่เชื่อมกับ 3D (สองทาง): คลิกคาน/เสาในหน้า 3D แล้วกด "← 2D: ชื่อชิ้น" (หรือปุ่ม ✎ ในแผงขวา — เสาเลือกแนว X/Y ได้) หน้า 2D เปิดโครงตามแนวกริดนั้นและเลือกชิ้นนั้นไว้
  - แก้ขนาดหน้าตัดของชิ้น หรือน้ำหนักแผ่บนคาน (DL/LL) ใน 2D → บันทึกเป็นค่าปรับรายชิ้นของอาคาร 3D ทันที (แสดงจำนวนและปุ่มล้างในการ์ดสร้างอาคาร)
  - แก้อาคารในหน้า 3D (ช่วงเสา ชั้น หน้าตัด น้ำหนัก ลม ฯลฯ) → โครง 2D สร้างใหม่อัตโนมัติ ทั้งเปิดคนละแท็บหรือสลับหน้า
  - การแก้รูปทรงใน 2D (ย้าย/เพิ่ม/ลบชิ้น) ส่งกลับ 3D ไม่ได้ — เมื่อ 3D เปลี่ยนจะถามก่อนทับ หรือกด "เลิกเชื่อม" เพื่อแก้ต่ออิสระ · โมเดล 2D เดิมสำรองไว้ กู้คืนได้
- แรงแผ่นดินไหว (3D): เปิดในการ์ดสร้างอาคาร → load case EX/EY ที่จุดอ้างอิงพื้น + แรงบิดเยื้องศูนย์โดยบังเอิญ 5%, ชุดผสม วสท. 0.75(1.4D+1.7L±1.87E), 0.9D±1.43E, ฐานรากตรวจด้วย 0.7E — ค่า Ss/S1/Fa/Fv/R ต้องตรวจกับมาตรฐานฉบับจริง (สเปกตรัมกรุงเทพฯ ยังไม่รองรับ)
- ตัวอย่าง 3D: บ้าน 2 ชั้น (ฐานแผ่), อาคารพาณิชย์ 4 ชั้น 3 คูหา (เข็ม 25 ตัน), สำนักงาน 8 ชั้น (เข็ม 80 ตัน) · ตัวอย่าง 2D: 2 ชั้น 2 ช่วง, โครงหลังคา 12 m, 5 ชั้น 3 ช่วง (P-Δ)
- หน้า 3D: ribbon, ป้ายกริด/ระดับชั้น, ตัวเลขบนแผนภาพ, หน่วยตัน, หน้าปก/สารบัญ/เลขหน้าในรายการคำนวณ, คำนวณใน Web Worker, tooltip เมื่อชี้เมาส์
